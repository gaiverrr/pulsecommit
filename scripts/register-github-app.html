Register the Pulse Commit GitHub App

Submitting this form will POST the manifest below to GitHub and create the Pulse Commit App under the GitHub Organization you specify. You must already be signed in to github.com in this browser, and the org must already exist (see the runbook, Step 1). 



  

    
    
  


  

    After clicking, GitHub will redirect back to a localhost-style URL
    (https://pulsecommit.app/auth/redirect) that may fail to load —
    that's expected. The App is created. Visit
    https://github.com/organizations/<org>/settings/apps/pulse-commit
    to confirm, copy the Client ID, and enable Device Flow (the manifest API has
    no field for it as of 2026).
